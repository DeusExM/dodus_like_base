# Éléments à restaurer séparément

Ne jamais mettre ces éléments dans Git :

- clés SSH GitHub
- Deploy Keys
- clé OpenRouter
- tokens OAuth Antigravity / Gemini
- fichiers .env
- tokens Tailscale
- mots de passe PostgreSQL
- autres clés API

Répertoires/fichiers typiques :
- ~/.ssh/
- ~/.gemini/
- fichiers .env
- configuration OpenCode utilisateur
